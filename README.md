# ecogate-router

이 프로그램은 mobileeco 사에서 생산한 ecogate (LG U+ Mobile Router) 휴대용 라우터의 데이터 사용량을 확인할 수 있는 프로그램입니다.

## 원리

기존에는 ecogate plus 휴대폰 앱을 통해 사용량을 확인했는데, 이것이 불편하여 제작하게 되었습니다.
에그에 연결 후 `192.168.255.1` 에 접속하면 관리자 페이지가 나오는데, 관리자 비밀번호를 입력하고 메인 화면에 들어가면 json 형태로 된 배터리 상태, 신호 세기, 남은 데이터 용량 등이 가공되어 표시되는 것을 알 수 있다. 해당 request 를 python으로 변경한 프로그램이 바로 이것이다.

## 사용법

```bash
./app.py
```

```bash
./app.py -h
```
